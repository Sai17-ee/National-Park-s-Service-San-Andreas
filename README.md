# National Park Service · San-Andreas

Премиальный адаптивный портал игровой фракции Gambit RP / SAMP.

## Запуск
Откройте `index.html` в современном браузере. Для корректной загрузки изображений, шрифтов и иконок нужен интернет.

## Что включено
- Один автономный HTML-файл с кастомными CSS и vanilla JavaScript.
- Адаптивная навигация и мобильное меню.
- Hero с параллаксом, анимации появления секций и счётчики.
- Горизонтальная карусель парков, аккордеоны документов.
- Демонстрационная форма заявки: проверяет поля и скачивает локальный TXT-черновик; данные никуда не отправляются.
- Внешние изображения Unsplash, Google Fonts и Font Awesome CDN.

## Перед публикацией
1. Замените `Имя_Фамилия`, статик и тестовую статистику реальными игровыми данными.
2. Добавьте реальные Discord/VK/Telegram-ссылки и ссылки на форум.
3. Проверьте разрешённые правилами сервера названия, документы и ранги.
4. Подключите серверный обработчик формы, если нужно принимать заявки онлайн.
5. Английский переключатель сейчас демонстрационный, полноценная локализация не подключена.

Все должности, показатели, новости и регламенты в шаблоне являются демонстрационными данными игрового портала.
